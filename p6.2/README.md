# String Tools (Reverse & Vowel Count)

Open `index.html` in a browser to use the small UI.

Features:
- Reverse a string (preserves all characters and whitespace)
- Count vowels (a, e, i, o, u) in a paragraph and show totals per vowel

No build required. Example:

```bash
# on macOS / Linux
open index.html

# or just double-click index.html in Finder
```
